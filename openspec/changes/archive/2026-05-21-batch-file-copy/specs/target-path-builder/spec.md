## ADDED Requirements

### Requirement: Three-segment path combination
The system SHALL provide three input segments for building target paths: Prefix (text input), Middle (list), Suffix (text input). Paths are generated by concatenating Prefix + each Middle item + Suffix.

#### Scenario: Basic three-segment path generation
- **WHEN** Prefix is "D:/exp/", Middle is ["a", "b", "c"], Suffix is "images"
- **THEN** generated paths are: D:/exp/a/images, D:/exp/b/images, D:/exp/c/images

#### Scenario: Suffix empty
- **WHEN** Prefix is "D:/exp/", Middle is ["a", "b"], Suffix is empty
- **THEN** generated paths are: D:/exp/a, D:/exp/b

#### Scenario: Single target without middle list
- **WHEN** Middle list is empty and Suffix is empty
- **THEN** only one target path is generated: the Prefix itself

#### Scenario: Middle item with nested path separator
- **WHEN** Prefix is "D:/exp/", Middle is ["a/b", "c/d"], Suffix is "images"
- **THEN** generated paths are: D:/exp/a/b/images, D:/exp/c/d/images

### Requirement: Prefix path browse with smart subfolder detection
The system SHALL provide a browse button for the Prefix input. When a directory is selected, if it contains multiple subdirectories, the system SHALL prompt the user to import them into the Middle list.

#### Scenario: Browse and detect subfolders
- **WHEN** user clicks the Prefix browse button and selects "D:/exp/"
- **AND** D:/exp/ contains subfolders: a, b, c, x, y
- **THEN** system SHALL show a confirmation dialog: "检测到 5 个子文件夹，是否导入到中间层列表？"
- **AND** offer Yes/No buttons

#### Scenario: Import selected subfolders
- **WHEN** user clicks Yes on the import prompt
- **THEN** a selection dialog opens showing all subfolder names with checkboxes
- **AND** provides "全选" and "全不选" toggle buttons
- **AND** user confirms selection
- **THEN** selected subfolder names are added to the Middle list

#### Scenario: Decline subfolder import
- **WHEN** user clicks No on the import prompt
- **THEN** the Middle list remains unchanged

### Requirement: Middle list manual editing
The system SHALL support adding, editing, and deleting items in the Middle list manually. Items support `/` as path separator for nested directories.

#### Scenario: Add item manually
- **WHEN** user clicks "+添加" button
- **THEN** an input dialog appears for text entry
- **AND** the entered text is added as a new item in the Middle list

#### Scenario: Delete item manually
- **WHEN** user clicks delete on a Middle list item
- **THEN** the item is removed from the list

#### Scenario: Manual entry with path separator
- **WHEN** user manually adds "a/b" to the Middle list
- **THEN** the system treats it as a valid entry and generates path with nested directory

### Requirement: Real-time path preview
The system SHALL display all generated target paths in a preview list that updates in real-time when Prefix, Middle, or Suffix changes.

#### Scenario: Preview updates
- **WHEN** user modifies any segment (Prefix/Middle/Suffix)
- **THEN** the preview list updates within 300ms debounce delay
- **AND** displays all generated target paths

### Requirement: Empty middle and suffix handling
When both Middle list and Suffix are empty, the system SHALL treat the Prefix as a single target directory.

#### Scenario: Single directory copy
- **WHEN** Middle list is empty and Suffix is empty
- **THEN** only one target path (the Prefix) is shown in preview
