## Context

在现有 KeyMacro 项目中增加文件批量复制功能，面向 Spine 动画师将资源文件分发到多个目标目录的场景。当前项目基于 .NET 9 + WinForms，已有一套完整的配置持久化、日志和 UI 体系。

新增功能独立于宏播放体系，作为独立窗口运行，通过主窗口工具栏按钮打开。

## Goals / Non-Goals

**Goals:**
- 源文件通过弹窗选择目录 + 缩略图预览 + 勾选，确认后只在主窗口显示文件路径列表
- 源文件列表支持去重追加
- 三段式目标路径组合：前缀 + 中间列表 + 后缀，实时预览
- 前缀目录选中后智能侦测子文件夹，提示导入至中间层列表
- 中间层列表使用多行文本框，逐行编辑，支持添加/删除/修改
- 多目标复制执行，同名文件冲突弹窗处理
- 前缀/后缀输入框历史记录下拉记忆，可一键清除
- 复制操作日志记录

**Non-Goals:**
- 不实现递归子目录扫描（仅当前目录一级）
- 不实现实时同步/监听文件变化
- 不做文件校验（MD5等），仅按文件名比较判断冲突
- 不支持跨网络路径的复杂权限处理

## Decisions

### 1. 源文件选择：弹窗模式
- **选择**：主窗口只展示已选文件路径列表（ListView/OListBox），点击"选择文件"弹出独立 `SourceFilePicker` 对话框
- **弹窗内容**：目录浏览 + ListView 缩略图（96x96） + 勾选 + 确认按钮
- **确认后**：选中文件路径追加到主窗口列表，已存在的文件自动去重（按完整路径比较）
- **主窗口列表操作**：支持全选/取消/删除选中项/清空

```
主窗口:
  已选文件 (3):
  ├ D:/spine/export/cha_idle.png
  ├ D:/spine/export/cha_walk.png
  └ D:/spine/export/cha_attack.png
  [选择文件]  [清除列表]

弹窗:
  目录: [D:/spine/export/] [浏览]
  ☑ cha_idle.png  ☐ cha_walk.png  ☐ cha_attack.png
  [确认选择]
```

### 2. 中间列表：多行文本模式
- **选择**：使用 `TextBox` 多行模式或简单的 ListBox，每行一条中间路径
- **导入子文件夹**：勾选确认后，所选名称逐行填入文本框
- **手动编辑**：用户可直接在文本框内增删改任意行
- **添加行**：按钮触发 InputDialog，确认后追加到文本框末尾
- **删除行**：选中行后点击删除按钮移除

### 3. 冲突弹窗路径格式化
- **选择**：调用 `explorer.exe` 前使用 `Path.GetFullPath(targetDir)` 标准化路径
- **理由**：路径拼接时使用 `/` 作为分隔符，explorer.exe 在 Windows 下可能无法正确解析混合斜杠路径，标准化为 `\` 确保打开正确目录

### 4. 历史记录：ComboBox 下拉记忆
- **选择**：前缀和后缀输入框改用 `ComboBox`（DropDown 模式），输入/选择过的内容自动记忆
- **存储**：历史记录保存到 `config.json` 的 `CopyPathHistory` 节点（`{ PrefixHistory: [...], SuffixHistory: [...] }`）
- **清理**：工具栏"清理历史记录"按钮 → 确认弹窗 → 清空两条历史列表
- **不再保留**原有的命名方案（Profile）保存/加载机制

### 5. 路径拼接规则
- **前缀**：保持原样，末尾不自动补 `/`
- **中间列表**：逐行读取，每行对应生成一个目标路径，支持 `/` 分隔多层级
- **后缀**：非空时拼接在中间项之后，自动处理首尾 `/`
- 空中间列表 + 空后缀 = 单一路径复制（前缀即最终目录）

### 6. 缩略图方案：ImageList + ListView（弹窗内）
- **选择**：在 `SourceFilePicker` 弹窗内使用 `ListView`（LargeIcon 模式）+ `ImageList`
- **异步加载**：`Task.Run` + `Invoke` 分批加载
- **限制**：最多 200 个文件，超出提示

### 7. 复制执行
- **选择**：`System.IO.File.Copy` 同步调用，串行执行
- **进度**：窗口底部状态栏显示当前进度
- **冲突**：每个目标目录独立弹窗，列出同名文件，提供覆盖/跳过/打开文件夹

## Risks / Trade-offs

- **缩略图内存占用**：大量文件（200+）时 ImageList 内存增长明显 → 限制 200 个上限
- **目标列表过长预览刷新**：中间列表 100+ 项时拼接预览频繁刷新可能卡顿 → 300ms 防抖
- **历史记录无限增长**：ComboBox 历史无上限 → 每次启动加载时自动去重，清理按钮可一键清除
