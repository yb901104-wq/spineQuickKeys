## Why

Spine 动画师在日常工作中经常需要将贴图/资源文件同时复制到多个目标目录（如不同客户端或渠道的资产目录）。这些目标路径结构相似，仅中间段存在差异。手动逐次复制效率低、易出错，需要一个专门的面板来批量处理。

## What Changes

- 主窗口工具栏新增"批量复制"按钮，点击打开独立的批量复制窗口
- **源文件选择面板**：浏览目录 → 缩略图列表展示图片文件 → 勾选需要复制的文件
- **目标路径配置面板**：三段式路径组合（前缀 + 中间列表 + 后缀）
  - 前缀输入框支持路径浏览按钮，选中目录后若侦测到复数子文件夹，提示是否导入至中间层列表
  - 中间层列表支持勾选导入、手动添加/编辑/删除，每项可用 `/` 分隔多层级
  - 后缀输入框可选留空
  - 实时预览所有生成的目标路径
- **冲突处理**：每目标目录独立弹窗，列出同名文件，提供覆盖/跳过/打开文件夹选项
- **目标方案保存**：可保存/加载/清理目标路径方案配置
- **复制进度与日志**：显示复制状态，记录操作日志

## Capabilities

### New Capabilities
- `source-file-picker`: 源文件目录浏览、缩略图列表展示、文件勾选
- `target-path-builder`: 三段式目标路径组合、中间列表管理、实时预览
- `file-copy-executor`: 多目标文件复制执行、冲突处理、进度反馈
- `copy-profile`: 目标路径方案的保存/加载/清理

### Modified Capabilities

无

## Impact

- `MainForm.cs` — 工具栏新增"批量复制"按钮
- `ConfigService.cs` — 新增复制方案配置的读写
- `OperationLogger.cs` — 新增复制操作日志记录
- 新增 `Forms/BatchCopyWindow.cs` — 批量复制主窗口
- 新增 `Services/BatchCopyService.cs` — 复制执行逻辑
