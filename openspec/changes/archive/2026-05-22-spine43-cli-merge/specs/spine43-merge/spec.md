## ADDED Requirements

### Requirement: 实验功能复选框
BatchCliWindow 合并 Tab 底部在执行合并按钮后方新增 `☐ 实验功能：CLI骨架合并(4.3)` 复选框。勾选后点击执行合并按钮时，弹出风险警告对话框，用户确认后方可继续。

#### Scenario: 勾选实验功能后点击执行合并
- **WHEN** 用户勾选实验功能复选框并点击"执行合并"
- **THEN** 弹出风险警告对话框，说明实验功能的风险和适用条件
- **THEN** 用户点击"确认"后开始实验合并流程
- **THEN** 用户点击"取消"则不做任何操作

#### Scenario: 未勾选实验功能
- **WHEN** 用户未勾选实验功能复选框并点击"执行合并"
- **THEN** 走原有 `-r` 集中合并逻辑，行为不变

### Requirement: 目标文件保护
实验合并流程不修改原始文件。创建目标文件的副本 `B_merged.spine`，所有合并操作在副本上进行。源文件和目标文件原始内容保持完整。

#### Scenario: 合并前创建副本
- **WHEN** 用户确认执行实验合并
- **THEN** 系统复制目标文件为 `{目标文件名}_merged.spine`
- **THEN** 所有后续操作针对副本文件执行

### Requirement: 版本检测与兼容
实验合并前通过 `Spine -i` 采集源文件和目标文件的版本号，根据版本号做兼容处理。

#### Scenario: 两者均低于 4.3.06
- **WHEN** 源文件和目标文件版本号均低于 4.3.06
- **THEN** 通知用户"两个文件均低于 4.3.06，将通过 -u 4.3.06 统一处理后合并"
- **THEN** 后续 CLI 命令自动添加 `-u 4.3.06` 参数
- **THEN** 继续执行合并流程

#### Scenario: 两者均 ≥ 4.3.06 且版本一致
- **WHEN** 源文件和目标文件版本号均 ≥ 4.3.06 且版本号相同
- **THEN** 不加 `-u` 参数
- **THEN** 继续执行合并流程

#### Scenario: 版本不一致（至少一方 ≥ 4.3.06）
- **WHEN** 源文件和目标文件版本号不一致，且至少一方 ≥ 4.3.06
- **THEN** 弹出报错对话框，说明版本不一致详情
- **THEN** 终止操作，不做任何修改

### Requirement: 动画采集与选择
实验合并前通过 `Spine -i` 采集源文件的动画列表。源文件 ListView 新增"动画"列，显示已选动画名。源文件列表工具栏增加"动画选择"按钮。

#### Scenario: 双击源文件行打开动画选择
- **WHEN** 用户在源文件列表双击某行
- **THEN** 弹出动画勾选对话框，列出该源文件的所有动画
- **THEN** 用户勾选需要的动画
- **THEN** 确认后"动画"列显示选择的动画名

#### Scenario: 点击动画选择按钮
- **WHEN** 用户在源文件列表选中一行并点击"动画选择"按钮
- **THEN** 弹出动画勾选对话框，列出该源文件的所有动画
- **THEN** 用户勾选需要的动画
- **THEN** 确认后"动画"列显示选择的动画名

#### Scenario: 未选择动画时默认全部
- **WHEN** 用户未做动画选择
- **THEN** 默认导入源文件全部动画

### Requirement: 骨架名输入框
BatchCliWindow 合并 Tab 增加可选的 `--from`（源骨架名）和 `--to`（目标骨架名）输入框。

#### Scenario: 骨架名输入框为空
- **WHEN** `--from` 或 `--to` 输入框为空
- **THEN** CLI 命令中不添加对应参数，Spine 默认取第一个骨架

#### Scenario: 骨架名输入框有内容
- **WHEN** `--from` 输入框有内容
- **THEN** 先通过 `Spine -i` 验证该骨架名在源文件中存在
- **THEN** 不存在则弹窗报错"骨架名不存在"，按默认走
- **THEN** 存在则在 CLI 命令中添加 `--from 骨架名`

### Requirement: 执行合并与动画导入
实验合并流程包含两步 CLI 操作：先 `--merge` 合并骨架，再 `-a` 逐个导入动画。

#### Scenario: 完整执行流程
- **WHEN** 所有前置条件满足
- **THEN** 执行 `Spine.com --ignore-unknown-args (-u 4.3.06) -i A.spine -o B_merged.spine --merge -r`
- **THEN** 执行 `Spine.com --ignore-unknown-args (-u 4.3.06) -i A.spine -o B_merged.spine -a anim1 -a anim2 ... -r`
- **THEN** 报告合并结果

#### Scenario: 动画名称冲突
- **WHEN** 目标文件已有同名动画
- **THEN** 弹出报错对话框，列出冲突动画名
- **THEN** 终止操作

### Requirement: 风险警告弹窗
勾选实验功能后首次点击执行合并时弹出警告对话框。

#### Scenario: 显示风险警告
- **WHEN** 用户勾选实验功能并点击"执行合并"
- **THEN** 弹出对话框显示风险说明：
  - 此功能依赖 Spine 4.3 CLI 的新功能
  - 使用前请确认已下载 Spine 4.3 版本
  - 合并可能导致版本不可逆升级，建议提前备份
  - 合并过程遇到命名冲突将报错终止
- **THEN** 提供"确认"和"取消"两个按钮
