## Why

Spine 4.3 CLI 新增了 `--merge` 骨架合并和 `-a` 动画导入功能，可以实现两个 `.spine` 骨架的全自动合并并保留所有动画。BatchCliWindow 当前的合并功能仅能通过 `-r` 做集中管理（多骨架独立共存），无法满足将两个骨架合并为单个骨架的需求。

## What Changes

- **BatchCliWindow 合并 Tab 新增实验功能**：复选框"☐ 实验功能：CLI骨架合并(4.3)"，勾选后有风险警告弹窗
- **实验合并流程**：备份目标文件为 `*_merged.spine` → `Spine -i` 采集版本号和动画列表 → 版本兼容检测 → `--merge` 合并骨架 → `-a` 逐个导入动画 → 报告结果
- **源文件列表扩展**：新增"动画"列显示已选动画；新增"动画选择"按钮（支持双击弹窗勾选），不选则默认全部动画
- **骨架名输入框**：可选的 `--from`（源骨架名）和 `--to`（目标骨架名）输入框，空白则默认取第一个骨架
- **版本检测与兼容策略**：
  - 两者均 < 4.3.06 → 统一加 `-u 4.3.06` 升级处理，通知用户
  - 两者均 ≥ 4.3.06 且版本一致 → 不加 `-u`
  - 任何版本不一致且至少一方 ≥ 4.3.06 → 报错终止
- 旧 `-r` 集中合并逻辑保持不变，实验功能开启前走原逻辑

## Capabilities

### New Capabilities
- `spine43-merge`: Spine 4.3 CLI 骨架合并与动画导入实验功能

### Modified Capabilities
无

## Impact

- `BatchCliWindow.cs`：合并 Tab 增加复选框、动画列、骨架名输入框、实验合并执行流程
- `SpineCliService.cs`：新增 `--merge` 和 `-a` 命令构建方法
- 无现有功能改动，原 `-r` 集中合并逻辑完整保留
