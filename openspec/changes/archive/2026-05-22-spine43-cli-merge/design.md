## Context

BatchCliWindow 现有的合并功能使用 `Spine.com -i A.spine -o B.spine -r` 做集中管理，将源骨架作为独立骨架导入到目标项目中。Spine 4.3 CLI 新增 `--merge` 和 `-a` 参数，支持真正的骨架合并和动画导入。

本功能为实验性质，通过复选框启用，不影响现有 `-r` 集中合并逻辑。

## Goals / Non-Goals

**Goals:**
- BatchCliWindow 合并 Tab 新增实验功能复选框及风险警告
- 实现基于 Spine 4.3 CLI 的骨架合并 + 动画导入完整流程
- 版本兼容检测（< 4.3.06 自动升级，版本不一致报错）
- 源文件动画选择（弹窗勾选 / 双击选择）
- 可选的 `--from`/`--to` 骨架名输入框
- 目标文件备份为 `*_merged.spine`，不修改源文件

**Non-Goals:**
- 不修改现有 `-r` 集中合并逻辑
- 不作为默认合并方式（需手动勾选实验功能）
- 不处理 skeleton 内部命名冲突（依赖 Spine CLI 自身行为）
- 不修改 Spine 4.3 以下版本的功能支持

## Decisions

### 1. 版本检测策略
`Spine -i` 命令采集项目版本号，做三分支逻辑：
- 两者 < 4.3.06 → 加 `-u 4.3.06` 统一处理
- 两者 ≥ 4.3.06 且版本相同 → 不加 `-u`
- 版本不一致且至少一方 ≥ 4.3.06 → 报错终止

### 2. `--from`/`--to` 输入框
- 空白 → 默认取第一个骨架
- 有内容 → 先用 `Spine -i` 验证骨架名是否存在，不存在则弹窗报错但按默认继续

### 3. 动画选择机制
- 通过 `Spine -i` 采集 A.spine 的动画列表
- 弹窗勾选（CheckedListBox），双击行也可触发展开
- 不选 = 全部导入；选部分 = 只导入勾选的
- 源 ListView 新增"动画"列显示已选动画名

### 4. 文件保护
不修改原始文件。复制 B.spine → B_merged.spine，所有合并操作在副本上进行。

### 5. 命令构建
所有 CLI 命令统一加 `--ignore-unknown-args`。
合并命令和动画导入命令分开执行（CLI 不支持合并为一条命令）。

## Risks / Trade-offs

- **[高] Spine 4.3 CLI 文档未完整**：`-a` 全部动画的语法可能尚未实现，需逐个传入动画名
- **[中] --merge 遇到骨骼/动画重名的行为不明确**：暂不加 `--replace`，先观察 Spine 4.3 的实际行为
- **[低] 旧启动器不识别 --merge**：通过 `--ignore-unknown-args` 透传参数给引擎
- **[低] 合并导致版本升级不可逆**：通过备份 `*_merged.spine` 保护原始文件
