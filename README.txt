Spine助手 - 使用说明
=====================
版本 V2.12

其实本质就是个快捷键宏工具，我是做spine的，针对Spine有特殊优化，制作目的是希望帮spine解决一些纪律性的，和功能性的重复劳动。
（spine的快捷键本身就很多了，其他宏软件和按键精灵，也能做这个软件能做的事，但是问题是很多低频但是纪律性或者必用的功能还要给他想一个快捷键觉得很麻烦，所以这个软件加了一个可以置顶的虚拟按钮，有的低频但是纪律性功能，直接点按钮多好。）
（当然其他软件也能用，但是记得不要载入spine快捷键hotkey文档，不然后面输入内容的时候，基于hotkey文件的自动检索和补全功能可能会干扰操作）。

功能：自定义按键序列、绑定触发快捷键（键盘热键/虚拟按钮）、后台自动播放。
附带 Spine 热键文件编辑器，可直接修改 Spine 的 hotkey TXT 文件。

一、快速开始
-----------

1. 启动程序：运行 KeyMacro.exe，系统托盘出现图标
2. 添加序列：主窗口点击 [添加] → 编辑按键步骤
3. 绑定触发方式：键盘全局热键 / 虚拟按键
4. 点击 [测试] 试播序列（当他不存在，这个测试按钮AI自己生成，虽然我也没搞懂为什么需要单独测试按钮，我也没测试过这个测试按钮的功能。就是先忘了删，后懒得删）
5. 启用虚拟按键浮窗：[开启虚拟按键] → 右键空白区域 → [增加按钮]
6. 给按钮绑定序列：在主窗口双击序列 → 点 [虚拟按键] → 再点击目标按钮
7. 给按钮绑定快捷键，在主窗口双击序列 → 点[键盘录入]或者[输入框]直接输入都可以。
8. 序列可以同时绑定一个快捷键和一个虚拟按键，两者可同时生效。

二、序列管理（主窗口）
-------------------

工具栏（从左到右）：

  添加       创建新序列
  编辑       打开选中序列的编辑器
  删除       删除选中序列
  测试       播放选中序列（立即执行）
  复制序列   复制选中序列（复制步骤，但清空热键绑定）
  暂停全部   停止所有正在播放的序列
  Spine热键编辑 打开 Spine 的 hotkey TXT 文件进行编辑
  释放       从软件内置资源中恢复默认的 Spine TXT 文件
  删除全部   删除所有序列（不可撤销）
  开启虚拟按键  显示所有已启用的虚拟按键窗口
  关闭虚拟按键  隐藏所有虚拟按键窗口
  管理虚拟按键  打开虚拟按键的多窗口管理面板
  导入 / 导出  导入或导出 .kmp 格式的完整配置包

列表说明：
  "触发快捷键" 列：显示绑定的键盘热键，或虚拟按键名称
  "循环(次)" 列：1=单次，>1=循环N次，0=无限循环（需要调循环数的序列，尽量在虚拟按键中选循环按钮，可以直接填循环数字）
  可以勾选/取消勾选行左侧复选框来启用或禁用某个序列
  关闭主窗口不会退出程序，程序会隐藏在系统托盘中继续运行


三、序列编辑器
-----------

打开方式：主窗口选中一个序列 → [编辑] / 或直接双击该序列

  【触发方式设置】
  每个序列可以选择一种触发方式（也可以不选，通过虚拟按键触发）：
  - [键盘录入]：打开键盘录制窗口，按下一个组合键完成绑定
  - [虚拟按键]：进入"拾取模式"，点击一个虚拟按键完成绑定
  - [清除]：清空已有触发热键
  注意：如果同时绑定了键盘热键和虚拟按键，两者都能触发同一个序列

  【步骤列表】
  表格每一行是一个步骤，各列含义：
  类型：单键 / 组合键 / 文本
    单键 = 按一个键（如 A、Space、F1）
    组合键 = 同时按多个键（如 Ctrl+C）
    文本 = 直接输入一段文字
  按键值：输入按键名称，支持自动补全提示
  延迟(ms)：此步骤执行完后等待的毫秒数（常用 50～200ms）
  按压方式：点按（按下即松）/ 长按（按住一段时间再松）
  按压时长(ms)：长按时保持按下的时间
  操作列：[复制] 可在当前行下方插入一行相同步骤

  【循环设置】（底部）
  循环次数：1=只执行一次，>1=重复执行N次，0=无限循环直到手动停止
  循环间隔：每次循环之间的等待时间（毫秒）


四、虚拟按键浮窗
---------------

虚拟按键是一个始终置顶的浮动工具栏，放置多个可点击的按钮。
每个按钮可以绑定一个序列，点击即播放。支持多窗口（多个独立浮窗）。

  右键点击按钮 → 弹出按钮操作菜单：
    修改按钮名称
    按钮循环延迟（仅循环按钮可用，设置循环间隔）
    按钮间距（在当前按钮后增加额外间距）
    强制停止（立即停止播放）
    删除当前按钮

  右键点击空白区域 → 弹出窗口操作菜单：
    增加按钮（标准 48×48 / 大 96×48 / 循环 110×48）
    删除所有按钮
    置顶 / 取消置顶
    透明度（40% / 60% / 80% / 100%）
    按钮位置锁定 / 解锁
    捕获目标窗口（点击后3秒内切换到目标窗口，捕获后将按键发给该窗口）
    清除目标窗口
    竖向模式（按钮改为竖向排列）
    缩放（50% / 75% / 100% / 150% / 200% / 自定义）
    窗口锁定 / 解锁（锁定后标题栏消失，窗口不可拖动）
    关闭窗口（仅隐藏，不删除）
    删除当前窗口（彻底删除，不可恢复）

  【多窗口管理】
  主窗口 [管理虚拟按键] → 打开管理面板：
  - 列出所有窗口，可分别启用/禁用、显示/隐藏、删除
  - [新增窗口] 创建新的独立浮窗
  - 每个窗口可以有自己的：名称、目标进程、按钮布局、缩放、方向、皮肤

  【目标窗口】
  捕获目标窗口后播放序列时：
  1. 优先用 PostMessage 方案发按键（不抢焦点，后台发送）
  2. 如果检测到按键无效，自动切换到激活窗口方案
  （不需要目标窗口的场景可以不捕获，按钮会直接用 SendKeys 发送）


五、Spine 热键编辑器
------------------

1. 主窗口点 [Spine热键编辑] → 选择一个 Spine 的 hotkey TXT 文件
2. 所有快捷键以表格形式列出，可直接修改按键值
3. 可在备注列添加中文说明（备注保存在同目录下的 .txt.annotations.json 文件，
   不影响原 TXT 文件内容）
4. 按键名会自动转换：你按键盘时用 Windows 键名，保存时自动转成 Spine 格式
   （如 Windows 的 "OemPeriod" → Spine 的 "PERIOD"）
5. [释放] 按钮：从软件内置资源恢复一套默认的 hotkey TXT


六、注意事项
-----------

  ● 单实例运行
    只能同时运行一个程序。重复运行 exe 会自动激活已有窗口。

  ● 启动延迟
    播放序列时，程序会先等 500ms 再开始按键，这是给你松开触发键的时间，
    避免按键串扰。

  ● 停止播放
    循环播放中的序列，再次点击触发按钮/热键即可停止。
    紧急情况可以用 [暂停全部] 或右键菜单 [强制停止]。

  ● 热键冲突
    如果某个全局热键注册失败（被其他程序占用），程序会自动跳过并记日志，
    不影响其他热键使用。程序退出后所有热键自动失效。

  ● 配置备份
    配置文件位置：
      序列和热键 → %APPDATA%\KeyMacro\config.json
      虚拟按键布局 → 程序同目录下的 virtual_layout.json
    建议定期通过主窗口 [导出] 功能备份完整配置（.kmp 文件）。

  ● 日志
    程序运行日志保存在 %APPDATA%\KeyMacro\logs\ 目录下，
    按日期分文件，自动清理 7 天前的日志。
    出问题时可以查看日志排查。

  ● 窗口锁定
    锁定虚拟按键窗口后标题栏消失，无法拖动和关闭。
    解锁方法：在按钮之间的空隙区域右键 → [窗口锁定/解锁]。

  ● 皮肤
    按钮和窗口外观可以通过替换 skins/ 目录下的 PNG 图片自定义。
    具体规范见 KeyMacro/SKIN_GUIDE.md。
    如果没有 PNG 图片，按钮会使用灰色渐变默认样式。

  ● 关闭与退出
    关闭主窗口 → 程序隐藏到系统托盘
    真正退出：系统托盘图标上右键 → [退出]
