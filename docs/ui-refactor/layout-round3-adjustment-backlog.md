# Round3 布局对齐差异清单

本清单根据 `docs/ui-refactor/comparisons/round3/` 的并排对比图整理。它用于下一轮继续修正布局，不属于 bug audit；如发现真实功能缺失或多出入口，再转入 `docs/audit.md` 或 `docs/ui-refactor/per-interface-adjustment.md`。

## 状态定义

- `已接受`：与概览图有差异，但由真实功能或阶段边界决定，暂不改。
- `待微调`：只涉及位置、尺寸、间距、比例，下一轮可直接改。
- `待确认`：会新增/减少真实信息或改变控件表达，需要确认后再改。
- `后续主题化`：属于深灰圆角、美术资源、按钮双态、自绘标题栏，不在布局阶段处理。
