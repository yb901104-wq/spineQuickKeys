# UI 布局标尺化对齐表

本文件用于“逐图逐控件标尺化对齐”。所有尺寸以概览图 1440x900 画布为参考，运行代码只能调整布局、尺寸、顺序和样式，不改变真实功能逻辑。若概览图与真实功能冲突，先在“冲突/确认项”记录，再由用户决定。

## 执行规则

1. 每次只处理一个界面。
2. 先写目标结构和控件尺寸，再改代码。
3. 改完后重新生成运行截图和并排对比图。
4. 若需要新增真实状态、合并功能、删除功能或替换控件类型，先记录为“待确认”。
5. 深灰圆角资源、按钮双状态图和自绘标题栏属于后续主题化阶段；当前阶段优先结构、位置、长宽。
