# UI 资源启用逐界面检查记录

本文件记录真实启用 UI 资源后的逐界面核对结论。原则：功能、按钮、列名和事件绑定以 `KeyMacro/Forms` 代码为准；概览图只指导该窗口自己的默认尺寸、布局方向和视觉层级，不能把概览图画布尺寸统一套给所有窗口。

## 当前尺寸修正规则

| 界面 | 当前默认尺寸 | 最小尺寸 | 检查结论 |
| --- | --- | --- | --- |
| MainForm | 1200x760 | 900x560 | 主窗口入口多，保留较宽窗口，但不再使用全局 1440x900。 |
| SequenceEditor | 1100x850 | 780x560 | 保持接近原始高窗口，步骤列表需要纵向空间。 |
| HotkeyRecorderForm | 580x360 | 420x240 | 弹窗尺寸独立，不参与大窗口尺寸。 |
| SpineHotkeyEditor | 1100x720 | 820x520 | TXT 文件区、搜索和三列表格需要中等宽度。 |
| VkWindowManager | 760x520 | 560x360 | 管理器只显示窗口列表和底部按钮，不应放大到主窗口级。 |
| BatchCopyWindow | 1100x760 | 820x620 | 源文件区、目标路径、预览和进度区需要较大但非全屏窗口。 |
| SourceFilePicker | 1000x700 | 760x520 | 缩略图浏览需要较大面积，但不等同 1440x900 概览画布。 |
| ConflictDialog | 620x430 | 520x360 | 冲突弹窗保持弹窗尺寸。 |
| BatchCliWindow | 1100x760 | 880x620 | 合并/导出双 Tab 信息密度高，使用中大型窗口。 |
| AnimationSelect | 520x560 | 420x420 | 动画选择是独立列表弹窗。 |
| ReNameTool | 900x560 | 820x500 | Designer 固定坐标较多，暂不硬拉大，避免出现大量空白。 |
| InputDialog | 520x220 | 420x180 | 通用输入弹窗保持小尺寸。 |
| SubfolderSelectDialog | 820x620 | 640x460 | 搜索、排除、勾选列表和确认按钮需要中等尺寸。 |

## 功能核对

| 界面 | 功能核准状态 | 备注 |
| --- | --- | --- |
| MainForm | 已核对 | 真实按钮仍为添加、编辑、删除、删除全部、复制序列、暂停全部、Spine热键编辑、释放、VK 三按钮、批量工具、CLI、导入、导出。 |
| SequenceEditor | 已核对 | 触发快捷键区仍为键盘录入、虚拟按键、清除；步骤列仍为类型、按键/文本、延迟、触发方式、按压时长、操作。 |
| SpineHotkeyEditor | 已核对 | 列仍为快捷键名称、快捷键、功能说明；未新增分组/状态列表。 |
| BatchCopyWindow | 已核对 | 保留源文件、前缀/中间/后缀、预览、清理历史、开始/取消复制和进度文本。 |
| BatchCliWindow | 已核对 | 保留合并/批量导出双 Tab、实验功能、导出配置选项和进度区。 |
| VkWindowManager | 已核对 | 仅管理器套主题；不触碰 VirtualKeyWindow 本体和 SKIN。 |
| ReNameTool | 已核对 | 三个 Tab 功能不变，`.bytes及.txt后缀` 仍是 checkbox。 |
| SourceFilePicker | 已核对 | 保留目录浏览、刷新、缩略图勾选和确认选择。 |
| ConflictDialog | 已核对 | 保留取消全部复制、跳过冲突、覆盖、打开文件夹。 |
| InputDialog / SubfolderSelectDialog | 已核对 | 只套主题和尺寸，不改变返回结果与筛选逻辑。 |

## 待后续视觉复查

- 需要用户手动运行发布版确认每个窗口的实际视觉，因为当前自动截图环境无法捕获有效桌面图像。
- `ReNameTool` 若要完全贴合 UI 概览图，需要后续单独重排 Designer 固定坐标控件；本次只做安全尺寸和主题启用。
- `VirtualKeyWindow` 本体仍按排除规则不改；只允许后续检查其右键菜单和相关输入弹窗。
