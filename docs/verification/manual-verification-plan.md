# KeyMacro 手工验证方案

本文档用于验证本项目软件每个界面、模块和可操作功能。执行验证时，发现的问题先记录到 `docs/verification/findings.tmp.md`，不要直接写入 `docs/audit.md`；待对话确认后，再决定是否追加到正式审核台账。

## 执行规则

1. 每个用例都需要截图验证，截图存放在 `docs/verification/screenshots/`。
2. 截图命名格式：`CASE-ID_步骤_结果.png`，例如 `MF-001_after-add-sequence.png`。
3. 每个失败或疑似失败项先记录到 `docs/verification/findings.tmp.md`。
4. 新问题进入正式修复前，必须先在对话中确认，再追加到 `docs/audit.md`。
5. 验证时尽量使用测试素材目录 `manual_test_assets/`，不要使用真实工作文件，除非用户明确同意。

## 测试素材目录

请按需把测试文件放到以下路径：

| 类型 | 路径 | 用途 |
| --- | --- | --- |
| Spine 热键 TXT | `manual_test_assets/spine_hotkeys/` | 测试 Spine 热键编辑、导入、导出、重复项检测。 |
| `.kmp` 数据包 | `manual_test_assets/kmp/` | 测试统一导入导出。 |
| 批量复制源文件 | `manual_test_assets/batch_copy/source/` | 测试源文件选择、缩略图、冲突复制。 |
| 批量复制目标目录 | `manual_test_assets/batch_copy/targets/` | 测试目标路径三段式拼接、冲突、取消。 |
| Spine CLI 项目 | `manual_test_assets/cli/projects/` | 测试 CLI 合并、导出、打包。 |
| CLI export.json | `manual_test_assets/cli/export_configs/` | 测试导出配置检测与切换。 |

如果缺少真实 Spine 项目或 Spine.com，相关 CLI 用例记录为“环境缺失，未执行”。

## 截图证据要求

| 阶段 | 必拍截图 |
| --- | --- |
| 操作前 | 初始界面状态、关键输入数据。 |
| 操作中 | 弹窗、右键菜单、录制窗口、冲突窗口、进度状态。 |

| 失败时 | 错误弹窗、异常状态、日志路径或临时发现记录。 |
