## 3. S6~S10：选中快照、互锁、单一执行核心、入口与校验

### S6 `GetSelectedExportEntries()`（R3 / D7=A）

按 `_lvExportFiles.Items` **显示顺序**遍历，取 `item.Selected && item.Tag is SpineCliEntry`，返回 `List<SpineCliEntry>` 快照。`SelectedItems` 是实时视图，导出途中改选或列表重建都会让目标漂移。开头顺带 `UpdateSelectionCount()` 兜底。

### S7 `SetCliActionsEnabled(bool)`（R1 / R2 / D5=A）

```csharp
private void SetCliActionsEnabled(bool enabled)
{
    foreach (var b in _exportActionButtons) b.Enabled = enabled;
    if (!enabled) return;
    _btnExport.Text         = ExportAllText;
    _btnExportSelected.Text = ExportSelectedText;
    _btnPack.Text           = PackAllText;
    _btnPackSelected.Text   = PackSelectedText;
}
```

只禁用 4 个导出类按钮；「保存为导出预设」「验证导出结果」保持可用。恢复时一并还原文案，彻底消除 R1。

### S8 `ExecuteExportCoreAsync(targets, pack, trigger)`（R6 / D2=A）

把原 `ExecuteExport` / `ExecutePack` 的两段 90 行循环**合并为一份**。行为逐字保留：

| 保留项 | 内容 |
|---|---|
| 临时目录 | `cli_export` / `cli_pack` + `Guid.NewGuid()` |
| CLI 调用 | `Export` / `ExportDefault` / `Pack`（签名零改动） |
| 缺省配置 | `missingList` + `cli_export_log.txt` + 对应 MessageBox 文案 |
| 结果搬运 | `MoveDirectoryContents` 同名覆盖策略不变 |
| 进度文案 | `批量导出: {name}` / `单纹理图: {name}` |
| 日志 | `CLI export failed/error` / `CLI pack failed/error` 与 `OperationLogger` |
| 取消 / 异常 | 临时目录清理、两条取消提示、汇总标题「导出结果」/「打包结果」 |

唯一变化：`total = targets.Count`、`foreach` 遍历传入快照，并用 `pack` 选择分支文案。核心流程：

```
SetCliActionsEnabled(false) → trigger.Text = 导出中.../打包中...
→ BeginCliOperation() → ShowProgress(true)
→ foreach (entry in targets) { 与 V3.2 逐字相同的循环体 }
→ 汇总 MessageBox
finally { ShowProgress(false); EndCliOperation(); SetCliActionsEnabled(true); }
```

### S9 四个入口

```csharp
private Task ExecuteExport()
{
    if (!ValidateExportReady()) return Task.CompletedTask;
    return ExecuteExportCoreAsync(_exportEntries.ToList(), pack: false, trigger: _btnExport);
}
private Task ExecuteExportSelected() => RunSelectedAsync(pack: false, trigger: _btnExportSelected);
private Task ExecutePack()
{
    if (!ValidateExportReady()) return Task.CompletedTask;
    return ExecuteExportCoreAsync(_exportEntries.ToList(), pack: true, trigger: _btnPack);
}
private Task ExecutePackSelected() => RunSelectedAsync(pack: true, trigger: _btnPackSelected);

private Task RunSelectedAsync(bool pack, Button trigger)
{
    if (!ValidateExportReady()) return Task.CompletedTask;
    var targets = GetSelectedExportEntries();
    if (!ValidateSelectionReady(targets)) return Task.CompletedTask;
    return ExecuteExportCoreAsync(targets, pack, trigger);
}
```

## 4. 施工期根因修正：最小窗口布局链（设计文档 §6.2 预测被证伪）

### 4.1 现象

设计文档预测「6 按钮在 1040×680 下自动换 2 行，由行 5 `Percent 100` 弹性吸收，不会裁切」。harness 首次最小窗口截图显示：**动作按钮行完全看不见**，输出目录行以下被裁。

### 4.2 布局诊断日志（harness `LAYOUT min:`）

```
win.Size=1040x680  Client=1024x641  clientBottomScreen=813
exportPanel screen=(211,312) size=1398x422     ← 比窗口还宽 374px
actionPanel boundsInPanel=(76,457,969,100)
_btnExport screen=(290,780) height=36 → bottom=816 > 813   ← 超出客户区
_lblSelectionCount screen=(286,876)                        ← 完全在窗口外
parent TableLayoutPanel size=1406x465   (exportContainer)
parent TabPage        size=1426x485
parent DarkTabControl size=1434x529
parent TableLayoutPanel size=1024x641  (最外层 layout)
```

### 4.3 根因（三级列宽默认 AutoSize 链式撑破）

1. 最外层 `layout`（`ColumnCount=1`）**未设 `ColumnStyles`**，默认按子控件 PreferredSize 撑列宽 → `DarkTabControl` 1434 → `TabPage` 1426 → `exportContainer` 1406 → `exportPanel` 1398。内容最小宽来自「6 按钮单行（约 969）+ 340px 预设列 + 76px 行标签」。
2. `actionPanel.AutoSize=true` 又按单行把自身撑到 969px，即使父 cell 只有约 566px 也不换行。
3. `exportContainer` 列 0 同样默认 AutoSize（且 `ColumnStyles.Add` 是**追加**，index 0 仍是 AutoSize，第一次修无效）。
4. 行 1（文件列表）是 `Absolute 250`，而行 5 的 `Percent 100` 位于按钮行**之后**——压缩行 5 无法让按钮行上移；窄窗口下前面所有固定行之和 > 容器高度，按钮行被推出可视区。

### 4.4 五处修复（均在 `BatchCliWindow.cs`）

| # | 位置 | 修改 |
|---|---|---|
| 1 | 最外层 `layout` | `ColumnStyles.Clear(); Add(Percent 100)` |
| 2 | `exportContainer`（仅导出页） | 同上，合并页容器零改动（INV-3） |
| 3 | `actionPanel` | `AutoSize = false`（保留 `Dock=Fill`、`WrapContents=true`），让宽度由 cell 决定、真正换行 |
| 4 | `exportPanel` 行样式 | 行 1 `Absolute 250` → `Percent 100`（列表吃弹性）；行 5 `Percent 100` → `AutoSize`（计数固定） |
| 5 | 源目录 / 输出目录行 | `FlowLayoutPanel + 固定 620px 输入框` → `TableLayoutPanel`（输入框列 Percent 100 + `MinimumSize 120`，按钮列 AutoSize），窄窗口不再换行，把高度还给列表 |

### 4.5 修复后

```
exportPanel size=982x422   (≤ 客户区 1024)
6 个按钮分 2 行，全部 screen bottom ≤ clientBottom
_lblSelectionCount 在客户区内
文件列表约 72px（表头 + 2 行，可滚动）；窗口拉大后由 Percent 行恢复
```

诚实说明：最小窗口下列表高度约 72px，属「功能区均可见、无裁切」，不宣称列表保持大面积；AC-17 断言按此口径设为 `>= 60` 并记录实际值。
