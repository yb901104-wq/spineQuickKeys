### C. 与设计稿的偏差（5 处，均为落地必需）

1. **D2 改采 A（顶栏原样保留）**：D4=A 的动画读取依赖 Spine.com 路径，若按推荐 B 把顶栏置灰会与功能自相矛盾；G3 报错文案已明确引导「窗口顶部」。
2. **6 列宽度按实机可用宽度收窄**：文档给的 `240/80/90/240/260` 合计 954px，而左列实机可用约 775px，会产生横向滚动并把 `Fill` 的目录列压没。实际采用 `210/72/82/210/150(Fill, MinWidth 130)`，静止合计约 768px；**列序、列名、`Fill` 保持在最后一列、tooltip 索引修正全部按文档**。
3. **报错弹窗为系统原生 `MessageBox`（浅色）**：施工文档 §6.1 明确指定 `MessageBox.Show`，且项目所有既有报错都是白底；渲染图中的深色弹窗是设计示意稿。已用 `TopLevelControl ?? this` 作为 owner，保证两层嵌套下模态层级正确。
4. **G3 的路径来源**：从 `ConfigService.LoadCliSpinePath()` 读取，等价于宿主顶栏 `SaveAndValidatePath()` 每次变更后的落盘值；因此**无需改动 `BatchCopyWindow.cs`**，R2「字节不变」得以保持。文档 §5.2 写「由宿主提供」，此处是实现等价形式。
5. **勾选列标红需额外 `CellPainting`**：`UiTheme.PaintGridCheckBoxCell` 只读 `grid.DefaultCellStyle` 且 `e.Handled=true`，会吞掉行级红底。故在 `RefreshVisualState()`（由宿主在 `UiTheme.Apply` 之后调用）里注册后置处理器重画首列，注册顺序晚于主题，实机截图确认整行红贯通。

## 0. 需求原文与硬边界

> 接下来我试图将批量复制标签页，合并进「CLI批量合并/导出」标签页中，作为旗下的子标签页放进「合并」页前面。
> 同时，在批量复制的源文件增加一个类似合并功能里的选择动画勾选动画的模式（旁边需要备注，**只能在列表中确定勾选的所有文件里只有 `.spine` 文件的时候可用，如果不满足这个状态会弹窗提示报错无法勾选**），勾选出来的动画在列表中增加一个动画列以展示，但是与合并功能里不同的是，这里的动画选择弹窗，如果你是勾选了多个 `.spine` 文件，得到的是**所有列表中的文件所拥有的动画（合并同名项）**。
> 勾选确定后，这里面每一个被勾选的文件都会选中这些动画，如果某些文件没有选中的部分动画，会将**这一行标红**，并且**只填写他有的动画**。也就是说标红只是提醒而非门槛，实际的门槛在于，不管你批量选了多少动画，**每个 `.spine` 文件他永远只会在这里选择他已经有的那部分动画**。
> 先写施工文档，然后再制作渲染图由我进行审查后再决定是否开启施工。

## 3. 动画选择功能规格（本次核心）

### 3.1 术语定义（后续各节严格使用）

| 符号 | 含义 |
| --- | --- |
| `C` | **勾选快照** = 点击「选择动画」瞬间的 `CheckedFilesSnapshot`（含被过滤隐藏但已勾选的项，口径见 D0） |
| `A(f)` | 文件 `f` **自身拥有**的动画名列表（来自 `GetProjectInfo`） |
| `U` | **并集** = `∪ A(f), f∈C`，同名项合并去重（大小写不敏感，见 D8） |
| `S` | **批量选择** = 用户在弹窗中勾选的动画集合，`S ⊆ U` |
| `E(f)` | **有效动画** = `S ∩ A(f)`，即该文件实际会被写入的动画 |
| `M(f)` | **缺失动画** = `S \ A(f)`，用于标红提醒 |

### 3.2 门槛（Hard Gate，逐条判定顺序）

| # | 条件 | 不满足时的行为 |
| --- | --- | --- |
| G0 | 当前无扫描 / 复制 / 备份任务运行（`!IsBusy && !_externalBusy`） | 按钮置灰，不可点击（沿用 `RefreshEnabledState()` `:922-948` 的锁定语义） |
| G1 | `C.Count > 0` | 弹窗提示「请先勾选要处理的文件」，**不打开动画弹窗** |
| G2 | `∀f∈C : Path.GetExtension(f).Equals(".spine", OrdinalIgnoreCase)` | **弹窗报错**：「无法勾选：已勾选的 N 个文件中有 M 个不是 .spine 文件」，列出违规文件名（最多 10 条 + 「…另有 X 个」），列出后**不打开动画弹窗、不修改任何动画数据** |
| G3 | Spine.com 路径有效（`_cli.IsValid`，仅当采用 D4=A 的 CLI 读取方案） | 弹窗提示「请先在窗口顶部设置有效的 Spine.com 路径」，不打开动画弹窗 |
| G4 | 至少一个文件成功读到动画（`U.Count > 0`） | 弹窗提示「未能从已勾选文件读取动画列表」，不写入 |

**门槛的准确表述（写进 UI 备注与报错文案）**：
> 只能在列表中确定勾选的所有文件里只有 `.spine` 文件的时候可用。

**G2 的两个易错点，施工时必须写单测/手测用例**：
1. 判定对象是**勾选项**不是「扫描到的全部文件」，也不是「当前可见行」——除非 D0 另选口径。
2. `.json` / `.skel` / `.png` / `.atlas` / 无扩展名 / `.SPINE`（大小写）中，只有大小写不敏感的 `.spine` 算通过；`.spine.json` 不算（扩展名是 `.json`）。

### 3.3 弹窗：并集 + 合并同名项

- 对 `C` 中每个文件调用 `GetProjectInfo`（串行、`async`、可取消），按 `FullPath + LastWriteTimeUtc` 做**内存缓存**，避免重复启动 Spine.com 进程（N 个文件逐个起进程可能耗时数秒，弹窗需显示「读取中 i/N」与进度）。
- `U` 的构造：**按 `C` 的顺序遍历、`A(f)` 内按原顺序追加**，`StringComparer.OrdinalIgnoreCase` 去重；展示保留**首次出现**的原始拼写（例：`walk` 与 `Walk` 视为同名，只显示先出现的那个）。
- 单个文件读取失败 → `A(f) = []`，该文件仍参与流程；弹窗顶部汇总「N 个文件中有 X 个未能读取动画」；确认后该文件 `E(f)=[]`、整行标红。
- 弹窗形态（沿用 `UiWindowProfile.AnimationSelect`）：
  - 标题：`批量选择动画 — N 个 .spine 文件`
  - 顶部说明条：来源文件数 / 并集动画数 / 读取失败数 + 一句「同名动画已合并；部分文件可能不含所选动画，确认后按各文件实际拥有的动画填写，缺项仅标红提醒」
  - `DarkCheckedListBox`：`CheckOnClick=true`，默认**全勾**（对齐合并页「空集合=全部」的直觉）
  - 「全选 / 全不选 / 确认 / 取消」；取消 = 零写入
- **与合并页的关键差异**：合并页 `U = A(单个选中文件)`；这里 `U = ∪ A(所有勾选项)`。

### 3.4 确认写入：交集 + 标红（需求的核心语义）

对 `C` 中**每一个**文件 `f` 执行：

```
E(f) = S ∩ A(f)                    // 大小写不敏感比对，输出保留 A(f) 内的原始拼写
M(f) = S \ A(f)
entry.AvailableAnimations  = A(f)
entry.SelectedAnimations   = E(f)
entry.HasMissingAnimations = (M(f).Count > 0)
动画列文本 = E(f).Count > 0 ? string.Join(", ", E(f)) : "（无匹配动画）"
整行标红   = entry.HasMissingAnimations
```

| 约束 | 说明 |
| --- | --- |
| **实际门槛** | 不管 `S` 勾了多少动画，每个 `.spine` 文件**永远只会写入它自身已有的那部分** `E(f)`；`M(f)` 一律不写入、不臆造、不报错误列表 |
| **标红只是提醒** | `M(f).Count > 0` 时整行标红，**不禁用勾选、不阻止主按钮、不弹二次确认、不改变执行集合、不影响复制/备份结果** |
| **不标红的情况** | `M(f) = ∅`（该文件包含全部所选动画）→ 正常底色，动画列写满 `S` |
| **空结果** | `E(f) = ∅`（例如该文件一个所选动画都没有）→ 动画列「（无匹配动画）」，整行标红，**文件仍参与复制** |
| **幂等** | 再次打开弹窗并确认 → 按新 `S` 全量重算 `E(f)` / 标红；未确认（取消）→ 保持上一轮结果不变 |

### 3.6 状态生命周期（数据放在哪、什么时候清）

| 事件 | 行为 |
| --- | --- |
| 数据载体 | 在 `BackupFileEntry` 上**新增 3 个纯内存字段**：`List<string> AvailableAnimations`、`List<string> SelectedAnimations`、`bool HasMissingAnimations`；**不写 `config.json` / `PathHistory`（R6）** |

| 维度 | 合并页（现状，不动） | 批量复制页（本次新增） |

### 5.3 确认写入与标红（伪代码）

```csharp
foreach (var path in snapshot)
{
    var entry = _scanned.First(e => string.Equals(e.FullPath, path, StringComparison.OrdinalIgnoreCase));
    var available = animByPath[path];                                     // A(f)
    var effective = selected.Where(s => available.Contains(s, StringComparer.OrdinalIgnoreCase))
                            .Select(s => available.First(a => string.Equals(a, s, StringComparison.OrdinalIgnoreCase)))
                            .ToList();                                     // E(f)
    entry.AvailableAnimations = available;
    entry.SelectedAnimations  = effective;
    entry.HasMissingAnimations = effective.Count < selected.Count;        // M(f) > 0
}
RefreshGrid();   // 重建行时按 HasMissingAnimations 套底色、按 SelectedAnimations 填动画列
```

> `selected` 是 `S`，`effective.Count < selected.Count` 等价于 `M(f) ≠ ∅`（因为 `S ⊆ U` 且 `E(f) ⊆ S`，去重后数量可直接比较）。

## 附录 B · 一句话语义速查

> **门槛**：勾选项必须全是 `.spine`，否则报错、不开弹窗。
> **弹窗**：所有勾选项的动画**并集**，同名合并。
> **写入**：每个文件写入 `并集中勾选的动画 ∩ 该文件自身动画`，缺失部分不写。
> **标红**：有缺失就整行标红，**只提醒、不拦截**，文件照常复制。
> **动画列**：展示每个文件实际写入的那部分动画；不参与任何复制逻辑。
