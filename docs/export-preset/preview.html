R10 · 文件列表「export.json」状态为什么总是不对

用户症状：扫描/选中文件后状态列不正确，点「刷新状态」也不变，必须把下方配置名单选切到别处再切回来才正常。
下表把症状与根因分开，修复方案见施工文档 §4.4。
修复前UI 与内部字段从窗口创建起就不同步
UI 选中：● finish.export.json
内部字段：_exportConfigName = "export.json"
原因：BuildExportTab() 先 Checked = true，之后才订阅 CheckedChanged，初始选中态不触发事件
G2.spine❌ 按 export.json 判定
G2-n1.spine❌ 按 export.json 判定
tx-xy.spine❌ 点刷新仍不变
切到 demotion 再切回 finish → 事件终于把字段改成 finish → 状态才「正常」
结果：用户每次都得手动来回切换配置名纠偏；点「刷新状态」无效，因为它读的仍是错误字段。
修复后单一真值源 CurrentExportConfigName
UI 选中：● finish.export.json
真值源：finish.export.json（一致）
F1 由单选项派生真值 · F2 修正初始化顺序 · F4 扫描后立即刷新
G2.spine✅ 扫描即正确
G2-n1.spine✅ 扫描即正确
tx-xy.spine✅ 刷新结果不变
F6 批量生成完成后、F7 激活预设后，都自动重算状态列
结果：打开窗口直接扫描即正确；刷新 / 切换配置名 / 激活预设 / 批量生成后状态列全部自动同步，无需任何来回切换。
根因（代码层）：BatchCliWindow.cs:1229 的 _rbFinish.Checked = true 早于 :1230 的事件订阅；字段初值 :58 为 "export.json"。AddExportEntry()（:564-586）与 RefreshExportStatus()（:1338-1353）都读这个错误字段，且扫描完成后没有再刷新。
不是文件损坏、权限、隐藏属性，也不是扫描漏文件 —— 磁盘扫描层完全正常，错误只在显示层的配置名取值。
对照图为设计标注稿，橙色/青色徽标不会出现在实际 UI；实机状态列沿用现有浅绿 ✅ / 浅红 ❌ 行底色。
